## This product build

Software tests check known behavior, error cases, trust boundaries and privacy. Actual native C2PA signing/tampering tests establish verification behavior for constructed fixtures. A real CPU image request establishes that the frozen runtime loads and executes. It uses a constructed geometric image and establishes no accuracy.

Scam-text rules have **no measured population accuracy**, calibrated probability, or real-world false-positive-rate claim. Unit tests include ordinary code notifications and warnings because false accusations matter, but a small hand-written set cannot establish generalization. No user study has been completed. English is the only supported rule language.

Do not advertise “99% accurate,” “fraud-proof,” “detects all AI,” “verifies a caller,” or “C2PA proves a transaction safe.” Useful future evaluation would measure safe next-step selection and false reassurance in a consent-based community pilot, followed by an independently labeled corpus with clear scope and uncertainty.
