          UNDER THE LENS

          Useful signals.
          Honest limits.

          Messages, calls, links and emails use inspectable English-language rules. We look for risky requests and address structure. We don’t visit links, authenticate pasted email headers, or identify a caller from their voice.

          A link can say one thing and point elsewhere

          For HTML emails, we compare a displayed web address with the link’s actual host. A difference is observable, but legitimate tracking links can differ too. Plain pasted text and screenshots can hide the underlying link. We do not follow redirects or inspect a website’s reputation.

          In Link mode, use Understand this address for normalized hostnames, connection and port details, and counts of path segments and query fields. Private path, query and fragment values are omitted. This local inspection does not fetch either address or verify ownership.

          Screenshots: read, then review

          Windows OCR extracts English text locally. Review and correct it before analysis. It can miss or misread words and links, especially small text. It does not establish who sent the message.

          QR codes: decode, then review

          QR images are decoded locally. Nothing is opened or visited. Review all decoded text before a separate content check; a readable code does not make a link or payment safe.

          Original email files

          Use Email to select an .eml file and explicitly analyze it. MIME headers, encoded text and HTML link destinations can provide context missing from a screenshot. Attachments are not opened or scanned.

          Images: two separate checks

          Content Credentials checks a file’s signed C2PA declarations against a local trust snapshot. A valid signature binds a statement to the file; it does not make everything depicted true. Missing credentials don’t prove anything about origin.

          The optional local image detector examines visual patterns. Its output is experimental. AI-origin evidence is not a fraud verdict.

          What has actually been measured?

          The optional CLIP / CommunityForensics image detector has not passed our release requirements. Historical evaluations of its decision policy left many images inconclusive and fell well below the required rate of correct definite answers. Its older 670-image binary score does not describe today's useful answer rate or real-world accuracy.

          Use image results as limited clues. Verify the publisher, context and any payment request independently. No replacement model passed all release requirements; none was installed.

          No accuracy claim is made for scam detection. The practice examples are educational scenarios, not an independent benchmark. Detailed historical results and their limitations are in the bundled evaluation notes.
