02 / CONTEXT

Metadata is a clue, not proof

Metadata can be edited or removed. Missing metadata does not prove AI generation or authenticity. A camera name or date does not verify the scene or its caption.

Only GPS presence is reported; coordinates are not returned. This workspace does not locate the scene, run a reverse image search or produce a model-based truth verdict.
