01 / MAKE IT EASY TO REACH

Put Pocket within reach.

  1. Open a trusted phone address in Safari.

    You need a reachable HTTPS address for this companion. This desktop’s 127.0.0.1 address points to the iPhone itself when opened on your phone; it does not connect to the computer.

  2. Add Pocket to your Home Screen.

    In Safari, open the Pocket guide, then open the page menu → Share → Add to Home Screen. Keep Open as Web App enabled when offered, then tap Add. Menus can vary with your iOS version.

  3. Prepare it once, then test it.

    In Pocket, expand Offline access, tap Prepare offline access and wait for its ready status. Before relying on it, disconnect and check that the guide opens. Browser storage can be removed by the system.

02 / COPY → REVIEW → CHOOSE

Start with the words.

  1. Copy only the part you need.

    In Messages, touch and hold the message. Use Copy, or Select then Copy when offered. Remove names, account details and codes you do not need.

  2. Paste into Pocket.

    Open Pocket and tap Paste copied text. This replaces any text already in the review field. Safari may ask you to allow or confirm pasting. If the button cannot read the clipboard, touch and hold the message field and choose Paste instead.

  3. Review before taking a next step.

    Correct the wording, select the request topics you see, then show next steps. Pasting does not check the message automatically. Clear private text when you finish.

A SCREENSHOT WORKS TOO

Use your iPhone’s Live Text.

Open your screenshot in Photos. Tap the text-detection button when available, select the relevant wording, and choose Copy Text. Then paste it into Pocket and correct recognition mistakes.

Copy the words rather than tapping a detected link or phone number. Live Text availability varies by language, region and device. If unavailable, type a short transcript.

This path uses Apple’s text selection, not the desktop OCR service. Pocket does not receive the screenshot. Photos and clipboard copies remain outside Pocket’s control.

Optional: make a text-only Shortcut

A manual recipe for apps that offer selected text in their Share Sheet. Messages and other apps may offer Copy without a text share action; use copy/paste in that case.

This is setup text, not an installable shortcut. Build and inspect it yourself in Apple Shortcuts. Nothing is installed or run by this page.

  1. Create a shortcut named Review in Pocket. In Details, enable Show in Share Sheet and restrict received input to Text.
  2. Add Copy to Clipboard, using Shortcut Input. Turn on Local Only when available and choose a short Expire At time.
  3. Add a URL action containing only your trusted HTTPS Pocket address. Then add Open URLs using that fixed URL action’s output. Never choose Shortcut Input or clipboard text as the URL.
  4. When a source app offers Share for selected text, run your shortcut. In Pocket, tap Paste copied text or use the field’s Paste menu, then review the text.

MANUAL APPLE SHORTCUTS RECIPE — REVIEW IN POCKET
1. New shortcut: Review in Pocket.
2. Details: Show in Share Sheet. Receive Text only.
3. Copy to Clipboard: Shortcut Input. Enable Local Only when available; set a short Expire At time.
4. URL: https://YOUR-TRUSTED-HOST/phone/
   Replace the placeholder with your reachable, trusted HTTPS Pocket address. No message text, query or fragment belongs here.
5. Open URLs: the fixed URL from step 4, never Shortcut Input or Clipboard.
6. From a text-sharing app, run the shortcut. In Pocket, tap Paste copied text or paste manually. Review and choose topics.
If the source app does not share text, use Copy and manual Paste instead.
This recipe is not an installed shortcut. Clipboard copies and OS sync are outside Pocket’s control.
