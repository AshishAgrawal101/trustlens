## Screenshot guidance, not a changed OCR runtime

Four frozen native OCR controls showed the relevant tradeoff: black text on transparent background returned blank while its white-background reference returned the expected text; white text on transparent background already returned the expected text and its black-background reference also did. Therefore this release adds only manual opaque-contrast guidance and a Screenshot-specific blank-result notice. It does not silently choose a background or alter extracted wording. White backgrounds can hide white text; use an opaque copy with contrasting text/background and review recognition before checking.

The actual Screenshot help was visible without uploading a file. Runtime OCR, frozen image processing and QR processing are unchanged in this slice. Native controlled-fixture observations are not a general OCR improvement, accuracy measurement, browser-upload recording or physical-phone result.
