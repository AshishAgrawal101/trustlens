# Quote comparison and tool directory v14 — 23 October 2026

TrustLens now covers literal wording changes as well as requests, claims, media and numbers. Quote & context compares two supplied versions using a bounded longest-common-subsequence calculation. It marks exact removed/added text with readable labels, colors and text decoration. Unmarked text is shared. Whitespace, case, punctuation and Unicode are preserved; the two versions can be reconstructed exactly from the computed parts. Duplicate text can have more than one valid alignment; the app makes no meaning judgment.

Both versions remain unverified. The tool does not authenticate quotations, visit sources, decide factual accuracy or intent, or determine whether a change matters. A matching quote can still be false or out of context. The page encourages reading the full account, setting, speaker, audience and surrounding wording. It runs locally without input network requests, storage, exports, dependencies or models. Each version is limited to4,000UTF16codeunits and800whitespace/nonwhitespace segments; the bounded table has at most801x801entries. Blank versions are rejected. Explicit submission is required. Edits discard old output; Clear/exit/Back erase both drafts and result nodes.
