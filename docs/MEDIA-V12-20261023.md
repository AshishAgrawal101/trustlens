# Media context v12 — 23 October 2026

TrustLens now supports a separate local Media context workspace for reviewing an image alongside its claimed story. The main landing page links it beside Claim & context. Existing message, email, call, link, screenshot, QR and image checks remain available.

Explicit inspection returns format, encoded and orientation-adjusted dimensions, byte size, and a bounded allowlist of editable capture-clock, camera and software labels. It reports GPS-related tag presence only; coordinates are not displayed or returned. Pillow may internally parse GPS while normalizing orientation. There is no location lookup, reverse image search, signed-provenance verification or origin model in this workspace. Metadata cannot establish scene, date, origin or caption truth.

The optional caption stays on the page and is never sent or parsed. File selection alone only previews. Clear/replacement/exit revoke the preview; cancellation and edits invalidate pending results. Server failures preserve the draft and give fixed retry guidance. Uploads are bounded before multipart parsing and decoded using the existing byte/pixel/format limits. No new dependencies or model changes.

Validation: 860 Python + 258 JavaScript tests pass, zero skips. Constructed JPEG/PNG/WebP and EXIF tests cover rotation, tag allowlisting, malformed metadata, bounds, and no model loading. Controller tests cover stale results, cancellation, timeout, server failure, schema rejection and literal text rendering. The frozen 12-case semantic contract is illustrative, not a real-world accuracy benchmark. Independent backend, controller and semantic reviews are in verification/media-context.

Actual Edge checks: page loaded, constructed caption typed, Clear emptied it and focused file selection. At 320px viewport, body/document width was305px with no horizontal overflow. Screenshots recorded. Native file upload remains unverified because browser upload approval was previously denied; no bypass attempted. Phone testing and human usability remain deferred. Existing model admission and student-authorship/eligibility gates remain open.
