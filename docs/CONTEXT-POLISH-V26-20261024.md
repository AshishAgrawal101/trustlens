# TrustLens v26 — clearer context worksheets

Claim & context now puts its eight optional source controls inside one native expandable section. The claim, context and event date remain visible. Entered source details stay enabled and included in Review even when closed; a fixed “Entries present” indicator avoids silently hiding retained work. Opening and closing changes visibility only. Examples open their populated sources, while Clear, page exit and Back erase entries and collapse the section.

Validation does not strand invalid fields inside the closed section. Native source-field validation opens it before browser focus; custom source-address errors also reopen entered source details and focus the existing error. Actual Edge checks covered both paths, keyboard summary activation, Tab from the closed summary to Review, collapsed populated accounts, retained results, examples and clearing.

At a 390px viewport with a 375px client area, the initial form height fell from 2,386.375px to 934.09375px, about 61%. Claim-to-Review distance fell from 2,225.1875px to 772.90625px. These are browser geometry measurements, not a human usability study. Both open and closed layouts fit at 320px. The pure claim review, date comparisons and fixed input-free plan are unchanged.

Numbers & context now prefixes its four calculated numerical facts with “About” and places a rounding explanation immediately before them. A near-total decline can round to -100% while Group B remains positive; the display now qualifies that figure visibly. The marker describes six-significant-digit presentation, not a confidence interval or an estimate of measurement uncertainty. Entered counts and totals in parentheses remain exact; zero-baseline relative change remains undefined. Both pure calculation functions are byte-identical, and no arbitrary-precision output upgrade is claimed.

The communication audit froze twelve constructed cases before examining current rules. A narrow adjacent “remember not to” guard now recognizes protective reminders immediately before existing sensitive actions. Positive reminders and later live requests still produce concerns. The initial diagnostic and all residual outcomes remain preserved: three other advice/history cases still raise warnings, and the German case is outside the English wording scope and unscored. This is a bounded regression correction, not a population-accuracy result or a new model.

The compact claim form, closed-source example review, native/custom validation and Clear worked offline. A smallest-supported positive reported percentage remained visible while relative change read “About -100%”; zero baseline and conventional exact-count examples also passed.
