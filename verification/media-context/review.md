The useful distinction is observed decoder output versus authenticated capture history. A camera tag does not prove camera origin; missing camera metadata does not imply AI. An editor name does not establish AI use or fraud; firmware does not prove an unedited file. Times may reflect capture, editing or export, with unknown timezone and mutable values. If dates are parsed, impossible calendar dates must not silently roll into another day. A future tag asks for clarification rather than disproving the caption. If no semantic date parser is implemented, report the supplied timestamp as unverified rather than inventing a future-date check.

GPS presence is the maximum admitted location information. No coordinates, derived place, altitude or raw EXIF should enter UI/API/export. Its presence does not prove where the scene occurred, and absence is not location/origin evidence. Orientation changes display order; dimensions must be clearly encoded or adjusted dimensions and never scene-truth evidence.

A freeform caption is user context, not an automatically evaluated claim. It should remain only in the local page and never enter the metadata request, filename, query or export. Fixed questions ask the user to find the original caption, separately verify dates/location and inspect available provenance. They must not imply reverse-image search, source visits or downloaded external evidence. Metadata is neither signed provenance nor a second pattern model.
